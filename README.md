# tobellinc

## 🏢 会社紹介

**tobellinc** は、革新的なソフトウェアソリューションの開発・提供を行う企業です。  
私たちは最新の技術を活用し、お客様のビジネス課題を解決するプロダクト・サービスを届けます。

## 🚀 ミッション

テクノロジーの力でビジネスと社会に新たな価値を創造し、人々の生活をより豊かにすること。

## 💡 事業内容

- ソフトウェア開発 / Software Development
- クラウドインフラ構築・運用 / Cloud Infrastructure
- 技術コンサルティング / Tech Consulting

## 🛠️ 技術スタック

主に以下の技術を活用して開発を行っています。

- **言語**: TypeScript / Python / Go
- **フレームワーク**: React / Next.js / Node.js
- **インフラ**: AWS / GitHub Actions / Docker / Kubernetes
